## 1-1.（ピラー）退院まで時間がない方へ｜愛知で退院日から逆算して進める施設探しの手順

| 項目 | 内容 |
| --- | --- |
| slug案 | `knowledge-after-discharge`（既存記事の全面改稿として実装。URL変更なし） |
| 想定クエリ | 退院 施設 入所／病院から 施設へ 退院／高齢者 退院 施設／退院 後 施設 種類 |
| meta description案 | 退院まで時間がない方へ。愛知県で退院日から逆算して施設探しを進める手順を、相談先・要介護認定・施設の選択肢の順に解説します。 |
| 編集枠 | リアンハート編集部（[編集方針](about-editorial-policy)） |
| 更新日枠 | 公開日＋最終更新日を表示 |

**冒頭結論（40-60字）**
> 退院期限が迫っていても、本人の状態・医療の必要度・予算の3点を整理すれば、退院日から逆算して候補施設を絞り込めます。

**リード文**
「退院してください、と言われたが、家では介護できない」。ご家族にとって最も慌ただしく、不安が大きい場面です。この記事では、愛知県で退院後の住まい探しを進めるときに「何を」「誰と」「どの順番で」決めればよいかを整理します。

**［H2］退院までに、まず何を決めればいいですか？**
最初に決めるのは施設ではなく、判断材料の整理です。次の3点がそろうと、候補は大きく絞れます。
1. **本人の状態**: 要介護度、認知症の有無、リハビリの必要性
2. **医療の必要度**: 医療処置の内容（この内容で受け入れ可否が分かれます）
3. **費用の上限**: 月額でいくらまで出せるか（年金額＋家族の支援額）
この3点は、病院の相談員に伝える情報としてもそのまま使えます。

**［H2］病院の誰に相談すればいいですか？**
多くの病院には、退院に関する相談を担当する**医療ソーシャルワーカー（MSW）**や地域連携室があります。MSWの業務は厚生労働省「医療ソーシャルワーカー業務指針」に示されており、退院援助（退院後の行き先の調整、施設の紹介・転院調整など）は主要業務のひとつです※14。
- すでにケアマネジャーがいる場合: ケアマネジャーにも並行して連絡
- 介護保険をまだ申請していない場合: 次の見出しへ
「家族だけで探さなければならない」状況ではありません。病院・ケアマネジャー・紹介事業者を同時に動かすのが近道です。

**［H2］要介護認定が間に合わないときは、どうすればいいですか？**
要介護認定は、申請から結果の通知まで**原則30日以内**とされています※4。退院期限がそれより短いことも珍しくありません。その場合も、
- 申請は退院を待たずに**入院中から**行えます（市区町村の窓口へ）
- 認定結果が出る前のサービス利用については、市区町村やケアマネジャーに相談できます（認定前の暫定的な利用の可否・手続きは保険者により運用が異なるため、必ず窓口で確認してください）
という進め方があります。「認定が出てから探し始める」と退院に間に合わないため、認定と施設探しは並行が原則です。

**［H2］退院後すぐに入れる可能性がある施設には、どんな種類がありますか？**
退院直後の受け皿として検討されることが多いのは次の3つです（詳しくは[1-3 退院後すぐに入れる可能性がある施設](knowledge-discharge-options)）。
- **介護老人保健施設（老健）**: 在宅復帰を目指してリハビリ等を行う施設※8。「家に帰る準備の場」。要介護認定と施設側の判定が必要で、長期入居を前提とする施設ではありません
- **介護付き・住宅型有料老人ホーム**: 民間運営。受け入れ条件と費用の幅が広い
- **サービス付き高齢者向け住宅（サ高住）**: 賃貸住宅型。状態によって向き不向きが分かれる
特別養護老人ホーム（特養）は原則要介護3以上で※5※9、申込みから入居まで時間がかかる場合が多いため、退院の受け皿と特養の申込みは分けて考えます（[3-3 退院期限があるのに特養だけを待つリスク](knowledge-tokuyo-discharge-risk)）。

**［H2］愛知県で、リアンハートは何を手伝えますか？**
リアンハートは愛知県を対応エリアとして、退院期限から逆算した施設探しを無料でお手伝いしています（無料の理由と紹介できる施設の範囲は[手数料の開示ページ](fees-disclosure)で説明しています）。
- 病院・ケアマネジャーとの情報整理【御社データ: 病院連携の実例・対応エリア】
- 期限内に見学・申込みまで進める段取り【御社データ: 相談から入居までの平均的な日数実績】
- 入居後の見直し相談（合わなかった場合の住み替え）

**独自コンテンツ枠（ピラーの差別化・公開前に必ず実データ化）**
> 【御社データ: 「退院相談で最初に確認する5項目」——実際の相談で使っているヒアリング項目を表にして掲載。公的情報の要約だけでは大手と差別化できないため、このピラーに最低1つは御社の実務ノウハウを入れる】
※受け入れの可否は施設・時期・本人の状態によって変わるため、「必ず期限内に入居できる」とはお約束できません。その前提で、現実的な選択肢を一緒に絞り込みます。

**CTA**
> 退院期限が決まっている方へ。期限から逆算して、今日からの動き方を一緒に整理します。
> ［相談してみる → #contact］［電話で相談する → tel:052-000-0000］

**出典**: ※4、※5、※8、※9、※14

## 1-2. 病院から施設へ移るには｜退院調整の流れと相談先（地域連携室・MSW・ケアマネ）

| 項目 | 内容 |
| --- | --- |
| slug案 | `knowledge-discharge-flow` |
| 想定クエリ | 病院から 施設へ 退院／退院 施設 入所／脳梗塞 退院 施設 |
| meta description案 | 病院から施設へ移るまでの流れを解説。医療ソーシャルワーカー（MSW）・地域連携室・ケアマネジャーの役割と、家族が準備すべきことを整理します。 |
| 編集枠 | リアンハート編集部（[編集方針](about-editorial-policy)） |
| 更新日枠 | 公開日＋最終更新日を表示 |

**冒頭結論（40-60字）**
> 病院から施設への移行は、病院の医療ソーシャルワーカーと家族・ケアマネジャーが連携して進めるのが基本の流れです。

**リード文**
脳梗塞や骨折などで入院したあと、「自宅に戻るのは難しい」と判断されることがあります。このとき病院側・家族側それぞれに役割があります。全体の流れを知っておくと、限られた入院期間を有効に使えます。

**［H2］退院調整とは何ですか？誰が進めるのですか？**
退院調整（退院支援）とは、退院後の生活の場と必要な支援を入院中に整える取り組みです。病院側の窓口は主に**医療ソーシャルワーカー（MSW）**や退院調整の担当看護師で、厚生労働省の業務指針において、退院後の生活や転院先・施設の調整はMSWの業務として位置づけられています※14。多くの病院では「地域連携室」「医療相談室」などの名称の部署が担当します。

**［H2］家族は何を準備すればいいですか？**
病院側との面談で次が共有できると、調整が早く進みます。
- 介護保険の状況（未申請なら早めに申請。結果通知は原則30日以内※4）
- 在宅介護が難しい理由（介護者の状況、住環境など）
- 費用の上限と、本人・家族の希望（場所、面会のしやすさなど）
この内容は施設側への申込みでもほぼそのまま使います。[1-1 ピラー記事](knowledge-after-discharge)のチェック項目もご活用ください。

**［H2］転院先・施設はどうやって決まりますか？**
一般的には、(1)本人の医療・介護の必要度の評価 → (2)受け入れ可能な施設種別の絞り込み → (3)個別施設への打診・見学・申込み、の順に進みます。
- リハビリを継続して在宅復帰を目指すなら老健※8
- 生活の場として長く住むなら有料老人ホーム・サ高住など
- 特養を希望する場合は、原則要介護3以上という要件があり※5※9、入居までの期間も読みにくいため、つなぎの施設と並行で検討します
施設ごとの違いは[既存記事: 施設の選び方](knowledge-facility-choice)で解説しています。

**［H2］紹介事業者（リアンハート）はどの段階で使えますか？**
どの段階でも構いませんが、**(2)施設種別の絞り込みの前後**で使うと進めやすくなります。病院は医療面の評価のプロですが、地域の個別施設の空き状況・費用感・雰囲気までは把握しきれないことがあります。リアンハートは愛知県内の施設情報をもとに、病院側の評価とご家族の希望を突き合わせて候補を絞ります【御社データ: 病院・MSWとの連携実績】。

**CTA**
> 入院中の今から動けば、選択肢は広がります。退院予定日をお聞かせください。
> ［相談してみる → #contact］

**内部リンク**: 1-1（ピラー）、1-3、knowledge-facility-choice
**出典**: ※4、※5、※8、※9、※14

## 1-3. 退院後すぐに入れる可能性がある施設はどれ？｜老健・有料老人ホーム・サ高住のつなぎ方

| 項目 | 内容 |
| --- | --- |
| slug案 | `knowledge-discharge-options` |
| 想定クエリ | 退院 後 施設 種類／高齢者 退院 施設／老健 有料老人ホーム 違い |
| meta description案 | 退院後の受け皿になりやすい老健・有料老人ホーム・サ高住の役割と「つなぎ方」を解説。特養待機中の現実的な組み立て方も紹介します。 |
| 編集枠 | リアンハート編集部（[編集方針](about-editorial-policy)） |
| 更新日枠 | 公開日＋最終更新日を表示 |

**冒頭結論（40-60字）**
> 退院直後の受け皿は老健・有料老人ホーム・サ高住が中心で、特養は待機を見込んで「つなぎ」と並行して申し込むのが現実的です。

**リード文**
「退院後の行き先」と一口に言っても、施設には役割の違いがあります。間違った種別に申し込むと時間を失います。ここでは退院直後の受け皿になりやすい3種別と、特養待機との組み合わせ方を説明します。

**［H2］老健（介護老人保健施設）はどんな施設ですか？**
老健は、リハビリテーション等を受けながら**在宅復帰を目指す**施設です※8。「終の住まい」ではなく、自宅や次の住まいへ移る準備の場という位置づけです。入所には要介護認定と施設側の判定が必要で、入所期間も状態に応じて見直されるため、長期の住まいとして当てにはできません。それでも、退院直後にリハビリを継続したい場合の有力な選択肢です。入所判定・継続判定の運用詳細は施設ごとに異なるため、打診時に確認します。

**［H2］有料老人ホーム・サ高住は退院の受け皿になりますか？**
なり得ます。民間運営のため施設数が多く、費用・受け入れ条件の幅が広いのが特徴です。
- **介護付有料老人ホーム**: 介護サービスが施設内で提供される
- **住宅型有料老人ホーム**: 外部の介護サービスを組み合わせる
- **サ高住**: 賃貸住宅に安否確認・生活相談がつく。介護度が高い場合は向き不向きの見極めが必要
医療処置が必要な場合は受け入れの可否が施設ごとに分かれるため、打診の段階で医療情報を正確に伝えることが重要です。種別ごとの詳しい違いは[施設の選び方](knowledge-facility-choice)へ。

**［H2］特養に入りたい場合、退院とどう両立させますか？**
特養（特別養護老人ホーム）は原則要介護3以上が対象で※5※9、愛知県の調査では早期入所を希望する要介護3〜5の申込者（待機者）は3,502人(2023年4月1日時点)です※6。申込みから入居までの期間は読みにくいため、
1. 退院の受け皿（老健・有料・サ高住）をまず確保する
2. 特養には並行して申し込む（複数施設への申込みも一般的です※6）
3. 入居の声がかかった時点で、住み替えるかを判断する
という「二段構え」が現実的です。詳しくは[3-2 待機期間と代替先](knowledge-tokuyo-waiting)と[3-3 特養だけを待つリスク](knowledge-tokuyo-discharge-risk)へ。

**［H2］つなぎ先を選ぶときの注意点は？**
- **費用の二重発生**: つなぎ先の入居一時金が高いと、特養へ移る際の負担が増えます。短期前提なら一時金が小さいプランを優先
- **住み替えの負担**: 本人の環境変化の負担も考慮し、住み替え回数は最小限に
- **医療費控除の扱いの違い**: 特養・老健は施設サービス費の一部または全部が医療費控除の対象になり得ますが、有料老人ホーム（特定施設入居者生活介護）は対象外とされています※1※2。控除の効果は所得等により異なります（詳細は[2-4 医療費控除](knowledge-cost-iryouhikoujo)）

## 2-3. 住民税非課税世帯の介護施設費用｜負担限度額認定（補足給付）と高額介護サービス費

| meta description案 | 住民税非課税世帯が使える介護施設の費用軽減制度を解説。負担限度額認定（補足給付）と高額介護サービス費の仕組みと申請先をまとめました。 |
| 編集枠 | リアンハート編集部（[編集方針](about-editorial-policy)） |
| 更新日枠 | 公開日＋最終更新日を表示 |

**冒頭結論（40-60字）**
> 住民税非課税世帯は、負担限度額認定で特養等の食費・居住費が軽減され、高額介護サービス費で自己負担にも上限が付きます。

**リード文**
「非課税世帯だと施設は安くなる」と聞くものの、何がどれだけ軽減されるのかは分かりにくいものです。柱になる2つの制度を整理します。

**［H2］負担限度額認定（補足給付）とは何ですか？**
特養・老健・介護医療院・ショートステイの**食費と居住費**について、所得段階に応じた負担限度額を設け、超えた分を介護保険が補う制度です※3。対象は原則として、世帯全員（世帯分離している配偶者を含みます）が市町村民税非課税の方です※19。**さらに預貯金等の資産要件があり、基準額は所得段階に応じて単身でおおむね500万〜1,000万円以下（夫婦の場合は各基準額に1,000万円を加算）です**※19。このため、非課税世帯でも資産状況によっては対象外になる場合があります【公開前確認: 公開時点の最新の段階区分・基準額を再確認（2026年8月見直し予定の情報あり）】。
所得段階ごとの具体的な負担限度額（食費・居住費の日額）は制度改定で変わるため、本欄には公開日時点の最新の表を掲載します※3【公開前確認: 適用期間・確認日・「最終確認はお住まいの市区町村へ」の注記つきで負担限度額表を作成】。
**申請先は市区町村の介護保険窓口**です。認定証の交付を受けてから施設に提示します。

**［H2］高額介護サービス費とは何ですか？**
1か月の介護保険サービス自己負担の合計が上限を超えたとき、超過分が払い戻される制度です※3。
- 市町村民税非課税世帯: 月24,600円（所得状況によっては月15,000円）
- 課税世帯（年収約770万円未満）: 月44,400円
※食費・居住費・日常生活費は対象外です※3。

**［H2］対象になるか、どうやって確認すればいいですか？**
1. 本人と世帯の課税状況を確認（市区町村の窓口・課税証明書）
2. 預貯金等の資産状況を確認（基準額は所得段階別。単身でおおむね500万〜1,000万円以下※19）
3. 市区町村の介護保険窓口で負担限度額認定を申請
有料老人ホーム・サ高住は補足給付の対象外のため、非課税世帯で費用を抑えるなら特養等の公的施設が軸になります※3。特養の申込みは[3-1 特養の申込みから入居まで](knowledge-tokuyo-application)へ。

**［H2］制度を使っても足りないときは？**
社会福祉法人等による利用者負担軽減制度、生活保護制度、自治体独自の支援などの選択肢があります（実施状況・適用条件は市区町村により異なります）。一人で抱えず、市区町村・地域包括支援センター、またはリアンハートにご相談ください。制度の適用判断は最終的に保険者（市区町村）が行います。

**CTA**
> 課税状況と年金額が分かれば、使える制度の当たりを付けてから施設探しに入れます。

同じ「老人ホームの支払い」でも、医療費控除の扱いは施設の種別でまったく異なります。国税庁の取り扱いを基に、施設種別ごとに整理します（個別の申告判断は税務署・税理士にご確認ください）。

**［H2］特養の費用はどこまで医療費控除の対象ですか？**
特別養護老人ホーム（指定介護老人福祉施設）は、施設サービスの対価として支払った**介護費・食費・居住費の自己負担額の2分の1**に相当する金額が対象とされています※1。日常生活費や特別なサービスの費用は対象外です※1。

**［H2］老健・介護医療院はどうですか？**
介護老人保健施設・介護医療院は、介護費・食費・居住費の自己負担額の**全額**が対象とされています※1（日常生活費・特別なサービス費用は対象外）。

**［H2］有料老人ホーム・サ高住の費用は対象になりますか？**
有料老人ホーム等で受ける**特定施設入居者生活介護は、医療費控除の対象外**と整理されています※2。家賃や管理費も医療費控除の対象ではありません。ただし、施設に住みながら利用する訪問看護・訪問リハビリ等の医療系サービスには対象となるものがあります※2。個別のサービスがどちらに当たるかは、国税庁タックスアンサー（No.1125・No.1127）と税務署でご確認ください※1※2。

**［H2］手続きや効果で気をつけることは？**
- 施設の領収書には医療費控除の対象額が記載されることが基本とされています※1。領収書は保管しておきましょう
- **保険金などで補てんされる金額は、支払った医療費から差し引いて計算します**※17。**高額介護サービス費の払い戻しを受けた場合も、医療費から差し引いて計算します**※1。特養の場合は、施設サービス費の自己負担額のみに対する高額介護サービス費の**2分の1に相当する金額**を差し引く取り扱いです※1
- **医療費控除は所得控除（税額を減らす仕組み）のため、効果は所得や他の控除の状況により変わります**※17。納める税額がない場合、還付の効果は限定されます
- おむつ代は、傷病によりおおむね6か月以上寝たきりで医師の治療を受けている場合に、医師発行の「おむつ使用証明書」があれば対象になります（要介護認定を受けている一定の方は、市町村長が交付するおむつ使用の確認書等で代えられます）※20
- 申告方法・必要書類の詳細は国税庁サイトまたは税務署へ。本記事は一般的な情報であり、個別の税務判断はできません
施設選びの段階から控除の違いを知っておくと、実質負担の比較がより正確になります（[2-1 費用ピラー](knowledge-cost-aichi)）。

> ［年金・予算で入れる候補を相談する → #contact］

**リード文**
特別養護老人ホーム（特養）は、費用面の負担を抑えやすい公的施設として希望者の多い選択肢です※9。一方で、申込みの仕組みは「先着順」ではないことなど、知っておくべき前提があります。愛知県で申し込む場合の流れを整理します。

**［H2］特養には誰が入れますか？（要介護3以上の原則）**
特養の新規入所は、**原則として要介護3以上**の方が対象です※5※9。これは2015年4月の制度改正によるもので、在宅での生活が難しい方を優先する趣旨です※5。

2. 知的障害・精神障害等を伴い、同様の状態が頻繁に見られる

4. 単身世帯・同居家族が高齢/病弱などで家族の支援が期待できず、地域の介護サービス等の供給も不十分

**［H2］申込みはどこに、どうやってしますか？**

- 申込書は各施設または市区町村の窓口で入手（名古屋市は市の情報サイトで待機者数等を公表しています※7）
- 必要書類・記載項目は施設・保険者により異なるため、申込み前に各施設・市区町村へ確認します

**［H2］申込みから入居まで、どれくらいかかりますか？**

**［H2］申込み中にやっておくべきことは？**

**冒頭結論（40-60字）**
> 特養の入居時期は事前に読めないため、退院期限がある場合は受け皿を先に確保し、特養は並行で申し込むのが安全です。

**リード文**
「特養に申し込んだから、声がかかるまで病院にいられるはず」——この見立てが崩れたとき、ご家族は数日で行き先を探すことになります。退院と特養待機を両立させる考え方を説明します。

**［H2］なぜ「特養だけを待つ」のは危険なのですか？**
理由は3つあります。
1. **入居時期が読めない**: 特養の入居は申込み順ではなく必要性の評価で決まるため※5、「あと◯か月」という予測が立てにくい
2. **退院期限は待ってくれない**: 病院の入院期間には治療上・制度上の区切りがあり、退院日は特養の空きと無関係に決まる
3. **直前の選択肢は狭い**: 期限直前に探し始めると、見学・比較の時間が取れず、費用や立地で妥協を強いられやすい
愛知県では早期入所を希望する待機者だけで3,502人おり※6、タイミングの保証はどこにもありません。

**［H2］二段構え（つなぎ＋特養申込み）はどう組み立てますか？**
1. **退院の受け皿を先に確保**: 老健（在宅復帰を目指すリハビリの場※8）、有料老人ホーム、サ高住など（[1-3 退院後の施設の種類](knowledge-discharge-options)）
2. **特養には並行して申込み**: 入居後も特養の申込みは維持できます。状態変化は施設へ連絡
3. **声がかかったら住み替えを判断**: つなぎ先の住み心地が良ければ、そのまま住み続ける選択もあります
つなぎ先選びでは、初期費用（一時金）を抑える・住み替え前提の契約条件を確認する、の2点が重要です。

**［H2］費用の二重負担はどう考えればいいですか？**
つなぎ期間中は「つなぎ先の費用」がかかりますが、特養待機中の在宅介護にも介護サービス費・家族の負担（離職・通いの交通費等）というコストがあります。比較は「つなぎ費用 vs 在宅維持の総コスト」で行うのが現実的です。特養・老健は医療費控除の対象範囲が広い点も比較材料になります※1（効果は所得等により異なります。[2-4 医療費控除](knowledge-cost-iryouhikoujo)）。

**［H2］どこに相談すればいいですか？**
入院中なら病院の医療ソーシャルワーカー（退院援助はMSWの業務として位置づけられています※14）、在宅ならケアマネジャー・地域包括支援センターへ。リアンハートは、退院期限から逆算したつなぎ先探しと特養申込みの両方を一緒に進めます【御社データ: 退院×特養並行の対応実例】。

**［H2］なぜ説得がうまくいかないのですか？**
本人にとって施設の話は、「住み慣れた家を失う」「見捨てられる」という不安に直結しやすいためです。認知症がある場合、新しい情報の理解や記憶の保持が難しく、一度の説明で納得を得ること自体が困難なこともあります。「正しく説明すれば分かってくれるはず」という前提を、いったん手放すことが出発点になります。
※認知症の高齢者は2022年時点で全国に約443万人と推計されており※16、同じ悩みを抱える家族は決して少なくありません。

**［H2］段階を踏むとは、具体的にどうすることですか？**
一般に、次のような小さなステップが使われます（合う・合わないは本人の状態によるため、ケアマネジャー等と相談しながら進めてください）。
1. **日帰りから**: デイサービス等で「家以外の場所で過ごす」ことに慣れる
2. **短期から**: ショートステイで「泊まる」を経験する
3. **見学は「下見」と言い換える**: 「入る」ではなく「見るだけ」のハードルにする
4. **本人が信頼する人から**: 子どもの言葉より、医師・ケアマネジャー・孫の言葉が届くことがある
重要なのは、**どの段階でも本人の不安（何が嫌なのか）を聞き取る**ことです。「家に帰れなくなる」が不安なら面会や外出の頻度を具体的に示す、といった対応につながります。

**［H2］家族だけで進めるべきですか？**
いいえ。むしろ第三者を入れるほうがうまくいくことが多い場面です。
- **ケアマネジャー・地域包括支援センター**: 本人の状態に合わせた進め方の相談
- **かかりつけ医**: 本人への伝え方で協力を得られることがある
- **施設・紹介事業者**: 認知症の方の受け入れに慣れた施設の選び方、見学時の配慮
リアンハートでは、「嫌がっている段階」からのご相談を受けています。見学の段取りや、本人に負担の少ない進め方を一緒に考えます【御社データ: 同様の相談実例（匿名化）】。

**［H2］急がないといけない場合はどうすればいいですか？**
徘徊・火の不始末など安全に関わる状況や、介護者が限界を迎えている場合は、段階を踏む時間がないこともあります。その場合は一人で判断せず、ケアマネジャー・地域包括支援センターに緊急性を伝えて相談してください。入居のタイミングの考え方は[4-2 施設に入れるタイミング](knowledge-dementia-timing)で詳しく扱います。

> **【今すぐ危険があるときは】** 行方不明は警察（110）、火災・急病・けがは消防・救急（119）へ。ご家族による虐待が疑われる状況や介護者の急病は、市区町村の窓口・地域包括支援センターへすぐ連絡してください。施設探しより先に、安全の確保が最優先です。

**リード文**

**［H2］検討を始めるべきサインにはどんなものがありますか？**
次のいずれかが当てはまったら、入居の是非はともかく**情報収集を始めるタイミング**です。
- **本人の安全**: 徘徊で警察のお世話になった、火の不始末、転倒の繰り返し
- **本人の健康**: 食事・服薬・清潔の維持が在宅サービスだけでは難しくなってきた
- **介護者の生活**: 夜間対応で眠れない、仕事への影響、介護者自身の体調悪化や気分の落ち込み
特に3つ目は軽視されがちですが、介護者が倒れると在宅介護は即座に立ち行かなくなります。介護離職や共倒れの手前で動くことが、結果的に本人のためにもなります。

> **【今すぐ危険があるときは】** 行方不明は警察（110）、火災・急病・けがは消防・救急（119）へ。介護者の急病や限界で本人を見られない状況は、市区町村の窓口・地域包括支援センターへすぐ連絡してください。

**［H2］「早すぎる」ということはありませんか？**
情報収集や見学が早すぎることはありません。理由は2つあります。
1. 認知症の高齢者は2022年の約443万人から2040年には約584万人に増えると推計されており※16、施設探しの競争環境が緩む見通しは立てにくい
2. 比較・見学・本人の心の準備（[4-1 嫌がるときの進め方](knowledge-dementia-refusal)）には時間がかかる
「申し込む」と「調べる」は別の行動です。調べておいて損はありません。

**［H2］認知症だと入れる施設は限られますか？**
認知症対応を掲げる施設は多くありますが、症状（特に行動・心理症状）によって受け入れ可否が分かれるのが実情です。また、特養は原則要介護3以上ですが、要介護1・2でも**認知症で日常生活に支障が出る状態が頻繁に見られる場合**は特例入所の対象事由に含まれています※5。グループホーム等の認知症対応型サービスも選択肢になります（種別ごとの受け入れ傾向は施設により差が大きいため、個別に確認します）。
受け入れ実態は施設ごとに異なるため、症状を具体的に伝えた上での個別確認が欠かせません。

**［H2］決断を先延ばしにしないために何ができますか？**
- 家族会議で「ここまで来たら施設」というラインを先に決めておく
- ケアマネジャーに「そろそろ検討すべきか」を定期的に聞く
- 候補施設を2〜3か所見学しておく（いざという時に即断できる）
リアンハートは、検討段階のご相談から、症状に合う施設の絞り込みまでお手伝いします【御社データ: 認知症相談の対応実例】。

| 編集枠 | リアンハート編集部（[編集方針](about-editorial-policy)） |
| 更新日枠 | 公開日＋最終更新日を表示 |

**冒頭結論（40-60字）**
> 施設入居は介護をやめることではなく、介護の役割を専門職と分担し、家族にしかできない関わりに戻る選択です。

**リード文**
「ここまで育ててもらったのに」「自分が楽になりたいだけではないか」。施設を検討するご家族の多くが、この罪悪感を口にされます。この感情は、親を大切に思っているからこそ生まれるものです。だからこそ、事実ベースで整理してみる価値があります。

**［H2］なぜ罪悪感を抱くのですか？**
「介護は家族がするもの」という価値観の中で育った世代にとって、施設は「手放すこと」に見えるからです。しかし現実には、認知症の高齢者は全国に約443万人（2022年時点）と推計され※16、介護の長期化・重度化を家族だけで支えること自体に無理が生じやすい時代になっています。罪悪感は「愛情の証拠」ではあっても、「在宅を続けるべき根拠」ではありません。

**［H2］施設入居は「介護の放棄」ですか？**
違います。入居後の家族には、専門職には代われない役割が残ります。
- **面会・外出**: 本人にとって家族との時間は施設では代替できません
- **意思決定の代弁**: ケアの方針、医療の選択は家族が担い続けます
- **生活の質の見守り**: ケアが本人に合っているかを見られるのは家族です
食事・入浴・夜間の見守りといった**体力を消耗する部分を専門職に任せ、家族は「家族にしかできないこと」に集中する**——これが施設入居の実像です。むしろ、疲弊しきった状態の在宅介護より、関係が良くなったという声も聞かれます【御社データ: 入居後の家族の声（本人・家族の同意を得た匿名事例）】。

**［H2］罪悪感が消えないときは、どうすればいいですか？**
- **一人で決めない**: きょうだい・親族と決定を分担する。「自分が入れた」ではなく「家族で決めた」にする
- **本人の安全と健康を基準に置く**: 「家にいてほしい」は誰の希望か、を一度言葉にしてみる
- **同じ経験をした人の話を聞く**: 公益社団法人「認知症の人と家族の会」は全国に支部があり、無料の電話相談（フリーダイヤル0120-294-456、平日10〜15時）や家族のつどいを行っています※21。市区町村・地域包括支援センターでも家族向けの相談先を案内してもらえます
- **入居後も関われると知る**: 面会頻度や外泊の運用は施設に確認できます
リアンハートの相談では、施設を勧めることを目的にしていません。在宅継続という結論になるご相談もあります【御社データ: 実際に在宅継続を提案した事例の有無】。気持ちの整理からで構いません。

**CTA**
> 「決めきれない」段階のご相談で大丈夫です。気持ちの整理からご一緒します。
> ［罪悪感ごと相談する → #contact］
